# Changelog

All notable changes to this project will be documented in this file.

## [1.0.1] - 2026-03-31

### Fixed
- Fixed `alwaysOnTop` behavior when interacting with the app while playing fullscreen games
- Window now properly maintains its position on top when clicking buttons, dragging, or navigating between screens
- Added helper function `ensureAlwaysOnTop()` to centralize window stacking logic

## [1.0.0] - 2026-03-30 - Initial Release

### Added
- Desktop overlay widget for displaying PoE Ladder rankings
- User configuration screen for selecting ladders and skins
- Window position persistence across sessions
- Links to open ladder and profile pages in browser
